# Process documents

These are our working documents, kept because the challenge asks what was built during the build
window and how — and because the numbers in them are the ones the code was written against. They
are **not** the deliverables.

| File | What it is |
|---|---|
| `PLAN.md` | The operating plan: stages and gates, the two-person split, the measured facts, the Q&A questions and their answers. §16 is the rule list for coding agents. |
| `build-plan.md` | The build reference written by the second team member's coding agent: tool contracts, evidence design, SQL patterns, stage acceptance criteria. Its §0 defers to `PLAN.md` where the two differ. |
| `PROGRESS.md` | The running handoff log between the two of us, stage by stage, including the corrections each of us made to the other's numbers. |
| `KICKOFF.md` | The starting brief handed to the coding agent on day one. |
